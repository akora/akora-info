# akora.info

Simple landing page for [akora.info](https://akora.info), built from the [astro-aria](https://github.com/miantiao-me/astro-aria) theme.

The site focuses on a visual project directory with screenshots and links to live domains.

## Stack

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)
- [pnpm](https://pnpm.io)
- Hosting: [Netlify](https://www.netlify.com)
- DNS/edge: [Cloudflare](https://www.cloudflare.com)
